# Roadmap

- Etap 1 (MVP) — zrobiony: profil prywatny, baza, dashboard, pomiary, 2-2-3, check-iny, dziennik, trening z autosave, A/B/C, blokady, raport tygodnia, eksport/import/szyfrowanie.
- Etap 2 — częściowo: biblioteka ćwiczeń, serie, progresja, timer, szablony, lista zakupów, zamienniki są. Brakuje: edytor przepisów, ilustracje ćwiczeń z legalnego źródła, edycja planu kcal/makro z UI poza silnikiem.
- Etap 3 — częściowo: wzorce, siła, raport AI są. Brakuje: osobne raporty 14/28 dni, galeria zdjęć z suwakiem.
- Etap 4: push (wymaga hostingu + VAPID), synchronizacja, skaner kodów (Open Food Facts), import Apple Health (eksport XML), natywny wrapper.
