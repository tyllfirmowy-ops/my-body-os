# Blokady bezpieczeństwa (src/domain/safety.ts) — pierwszeństwo przed A/B/C

- Ból w klatce, omdlenie, nagła ciężka duszność → brak treningu, komunikat 112.
- Obrzęk, blokowanie, niestabilność kolana, brak obciążenia nogi, pogorszenie po treningu, nowy silny ból lub ból kolana ≥6 → stop ćwiczeniom nóg, rekomendacja konsultacji wg nasilenia.
- Ból kolana 3–5 → pomiń wstawanie z ławki, reszta nóg tylko do 3/10.
- Ból ≥4 w serii → przerwij ćwiczenie, następnym razem −15%.
- Kolano bez oceny specjalisty → plan nóg ostrożny (bez przysiadów/wykroków/skoków, step-up bez obciążenia).
- Senność za kierownicą → przerwij jazdę, zgłoś lekarzowi. Bez energetyków i przedtreningówek.
- Brak diagnoz: tylko obserwacje i tematy do lekarza. Plan C nigdy nie oznacza głodówki. Brak karnego cardio.
